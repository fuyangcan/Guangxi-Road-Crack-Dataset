# Guangxi Road Crack Dataset

[中文说明](README.md)

## Overview

The Guangxi Road Crack Dataset is a self-collected research dataset comprising **3,251 road crack images**, corresponding **pixel-level annotations**, and accompanying **text prompts**. It is intended to support academic research on road crack detection, segmentation, and related multimodal vision tasks.

Because the source images may contain information about surrounding infrastructure and the data collection environment, the full dataset is **not available for direct public download** from this repository. Researchers may request access using one of the application forms below. Data may be supplied, with appropriate processing, according to the approved research scope.

> **Note:** This repository contains access-request materials only. It does not constitute public release of the full dataset or automatic permission to use it.

## Availability of Data and Text Prompts

Road crack images, pixel-level annotations, and corresponding text prompts are not currently available for direct public download. Access to all three components is subject to application and review. Researchers may email huweijie_fl@163.com directly, describing their research purpose, intended use, and scope, or email a completed application form available below. Approved applicants may receive appropriately privacy-processed data and corresponding text prompts within the approved scope.

## How to Request Access

1. Download the Chinese or English form. Use the DOCX file to type your responses, or print and complete the PDF.
2. Complete the applicant and institutional details, describe the intended research, specify the requested data, and sign the form.
3. Email the completed form to the dataset contact below, using a subject such as “Guangxi Road Crack Dataset Access Request – Name – Institution”.
4. The data provider will consider the request in light of the stated research purpose and applicable use conditions. Any approved data delivery arrangements will be communicated separately.

**Application email: `huweijie_fl@163.com`**

To protect personal information, applicants should **not** post completed forms in public GitHub issues.

## Data Use Conditions

Any data supplied through an approved application may be used only for the **non-commercial academic research** described in the application. Redistribution to third parties and public release of the images, pixel-level annotations, or text prompts require prior authorization from the data provider. Researchers must handle collection-environment information appropriately and acknowledge the data source in resulting scholarly outputs, following any citation requirements provided with the data.

No public license for the underlying images, annotations, or prompts is granted through this repository. Downloading the application forms does not grant access to the dataset.
