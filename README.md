# 广西道路裂缝数据集 | Guangxi Road Crack Dataset

[English](README_EN.md)

## 数据集简介

广西道路裂缝数据集为自建的道路裂缝研究数据集，包含 **3,251 张道路裂缝图像**及对应的**像素级标注**，并提供配套的**文本提示**。数据集可用于道路裂缝检测、分割及相关多模态视觉研究。

由于原始图像可能包含道路周边设施与采集环境信息，本仓库**不提供完整数据集的直接下载**。研究人员可下载申请表，提交使用申请；符合使用条件的申请者可按批准的研究范围获得经必要处理的数据。

> **说明：本仓库提供数据访问申请材料，不代表数据集已经开放下载，也不构成自动授予使用权限。**

## 数据与文本提示获取方式

道路裂缝图像、像素级标注及对应文本提示目前均未公开提供直接下载，均采用申请审核方式提供。研究人员可直接发送邮件至 huweijie_lf@163.com，说明研究目的、数据用途及使用范围；也可下载下方申请表，填写后发送至同一邮箱。获批后，数据提供方将按批准范围提供经过必要隐私处理的数据及对应文本提示。

## 申请流程

1. 下载中文或英文申请表（建议使用 Word 填写，也可打印 PDF 后填写）。
2. 如实填写申请人信息、研究用途和预计使用期限，并完成申请人签名。
3. 将填写完成的申请表发送至下方数据集联系人邮箱，邮件主题建议为“广西道路裂缝数据集使用申请 — 姓名 — 单位”。
4. 数据提供方依据申请用途与使用要求处理申请。获准后，将另行沟通数据交付范围及方式。

**申请接收邮箱：`huweijie_lf@163.com`**

为保护申请人的个人信息，请勿通过公开 Issue 提交已经填写的申请表。

## 数据使用要求

申请使用的数据仅限申请表列明的**非商业学术研究**。未经数据提供方许可，不得将数据转交第三方或公开发布获取的图像、像素级标注及文本提示。申请人应采取适当措施保护与采集环境相关的信息，并在产生学术成果时注明数据来源、遵循后续提供的引用要求。

本仓库没有提供原始数据或标注的公开许可授权。下载本仓库中的申请表不代表获得数据使用权。
